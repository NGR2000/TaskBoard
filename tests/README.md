# テスト

GAS のバックエンドは、これまで本番にデプロイしないと動作を確認できなかった。
`gas_harness.js` は `SpreadsheetApp` / `PropertiesService` などを最小限だけ偽装して
`コード.js` をそのまま Node 上で走らせる。シートの中身も検証できる。

```bash
node tests/backend_test.js   # フライトの登録・アーカイブ・列移行・トークン検証
node tests/date_test.js      # タスクシート日付の解析（4形式）
```

特に見ているのは、退行しやすい2箇所:

- **再登録でアーカイブ状態が消えないこと** — `saveFlight` の更新は行を全列上書きするため、
  `archived` を読んで書き戻さないと訂正のたびに解除されてしまう
- **トークン未設定時に素通ししないこと** — 空トークンが空の期待値と一致してしまう事故を防ぐ
