ログイン

管理者として登録されたメンバーだけが使えます。招待メールからパスワードを設定してください。

パスワードを設定

8文字以上で設定してください。次回からはメールアドレスとこのパスワードでログインします。

管理者として登録されていません

ログインはできていますが、このアカウントは admins 表に入っていないため操作できません。 Supabase の持ち主に、このメールアドレスを admins に追加してもらってください（README.md「メンバーの追加」）。

📷 写真だけで速報登録（会場用）
